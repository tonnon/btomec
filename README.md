# Landing Page BTOMEC

Este repositório contém o código-fonte da landing page da **BTOMEC**, uma empresa especializada na fabricação de moldes de alta precisão para os setores de cosméticos, farmacêutico, higiene e alimentício. A página foi desenvolvida com um design moderno, animações suaves e é completamente responsiva, garantindo uma experiência de usuário fluida e profissional.

## Funcionalidades

- **Design moderno e clean**: Layout simples e profissional com animações sutis.
- **Responsividade**: A página se adapta a diferentes dispositivos (desktop e mobile).
- **React e TypeScript**: Utiliza o React para a criação da interface e o TypeScript para tipagem estática, garantindo maior segurança no código.
- **Tailwind CSS**: Utiliza o Tailwind CSS para estilização rápida e personalizada, permitindo um design moderno e flexível.

### Seções Principais

1. **Seção Hero**: Apresenta o branding e slogan da BTOMEC.
2. **Sobre nós**: Informações sobre a expertise e experiência da BTOMEC.
3. **Serviços**: Detalhes sobre os moldes de precisão e o que a empresa oferece.
4. **Portfólio ou Clientes**: Destaques de projetos ou clientes importantes.
5. **Formulário de contato**: Para contato direto ou chamada para ação.

## Tecnologias Usadas

- **React**: Biblioteca JavaScript para construção da interface de usuário.
- **TypeScript**: Superset de JavaScript para adicionar tipagem estática e garantir maior robustez no código.
- **Tailwind CSS**: Framework utilitário de CSS para estilização rápida e responsiva.
- **Vite**: Ferramenta de build para desenvolvimento rápido e eficiente.
